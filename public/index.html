Disentangled Soft-Prompt Architecture

Standard fine-tuning suffers from catastrophic forgetting when transferred to low-resource languages. Our architecture decouples prompt parameterization into two virtual token sets:

1. Task Anchor Prompt (P_task)

Trained on high-resource source languages (e.g., Hindi) to capture invariant entity boundary logic (PER, ORG, LOC).

2. Language Adaptation Prompt (P_lang)

Adapted in a parameter-efficient manner to encode script, agglutinative morphology, and syntactic alignment for target zero-shot languages.

3. Script Normalization & Agglutinative Stripping

Preprocessor pipeline applies NFKC normalization, zero-width cleanup, and suffix stripping for agglutinative languages like Tamil, Telugu, and Kannada.
